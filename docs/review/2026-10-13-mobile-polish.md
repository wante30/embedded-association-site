# 手机与全站视觉优化 · 2026-10-13

## 基线与范围

从 master fa7c48c（PR #5）创建 design/mobile-visual-polish。根据用户“优化手机页面、首页电路图看不见、全方位优化前端”的要求，改进页面呈现和信息层级。前一轮事实与部署审计见 [此前审计](2026-10-13-audit.md)。

本轮使用现有照片与背景，保留 React / TypeScript / Vite、自定义路由、base-aware 资源处理和 GitHub Pages 发布方式。不新增依赖、后台或报名功能；site.json 的协会事实、项目、奖项和公开成员记录不变。

## 视觉判断

- 原手机背景在本身较暗的图片之上叠加低透明度和多层遮罩，电路主体难辨。
- 首页先方向、再三张同等项目卡，慧枢不够突出；重复宣言与邀请拉长阅读。
- 10–13px 的正文、过小的搜索/菜单控件、三列窄页脚削弱手机可读性。
- 成员大尺寸中性头像、长资源卡片占据过多空间；协会合照被遮罩和英文装饰盖住。
- 项目架构被排成串联箭头，不能准确表达这些模块的职责关系。

## 设计与实现

延续深蓝、白、电光蓝：深色主视觉 #06141f、白色内容区、浅灰 #f4f7fa、文字 #142535、电光蓝 #246bfd、浅青 #8adafd。使用系统无衬线字体，不增加字体请求。以清楚可辨的电路照片作为首页特征，不增加 HUD、粒子或动画。

- 桌面首页采用左文右图；手机文字与图片分区，矮屏进一步压缩间距。背景始终走 assetPath。
- 首页依次展示协会、慧枢重点项目、学习方向、真实活动；历史项目保留文字入口。概览改为成立年份、地点、指导教师。
- 重点项目和演进入口读取同一份 JSON。手机活动改紧凑图文条目，保留真实照片、标题和日期。
- 提高正文与辅助信息可读性；主交互至少 44px，搜索文字 16px；菜单保留原生 dialog，补充当前页语义。
- 资源卡片改紧凑结构；成员使用小中性图标与姓名/角色横排；页脚两列导航加整行联系方式。
- 协会合照使用自然亮度与独立图注。项目图限制手机高度，完整展示现有照片。
- 项目档案使用 dl/dt/dd；技术组成改为无串联箭头的功能组，并提供相关项目入口。
- 页面标题直接标明“项目展示 / 活动记录 / 竞赛荣誉 / 协会成员 / 学习资源”。奖项原文与等级不改。

## 验收方法

Node 内容与路径契约、TypeScript 构建、根路径浏览器验收，再重新构建并验收 Pages 子路径，全部顺序执行。浏览器检查包括全部 14 个已知路由、未知地址、图片解码、真实图片不回退、控制台、刷新及 320 / 360 / 390 / 768 / 1024 / 1440 / 1920px 响应式表现。

新增 320×568 和 390×844 触控场景，测试菜单首尾入口、关闭与焦点恢复、滚动锁定、44px 主触控区、16px 搜索、首页项目跳转。系统模块检查真实内容与几何边界，不绑定 flex/grid 的具体实现。

背景解码和非零区域不能证明照片清楚；必须目检手机首屏、电路区域及桌面截图。现有低分辨率项目图仍有细节限制；没有生成虚假实物图、虚构原图细节或新增未经确认的事实。

本地结果：19 项 Node 测试通过，根路径与 Pages 构建通过；两套浏览器验收各 646 项检查、36 张报告内截图，errors 均为空。390px 首页由 6070px 缩至 4270px，约减少 30%；资源页由 3946px 缩至 3527px。
