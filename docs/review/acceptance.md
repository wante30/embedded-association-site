# 视觉与功能验收

## 当前验收方式

日期：2026-10-13。事实与部署基线见 [此前审计](2026-10-13-audit.md)，当前前端范围见 [手机与全站视觉优化](2026-10-13-mobile-polish.md)。早期离线组件截图不作为当前生产构建的证据。

- `npm test`：协会事实、公开记录、资源文件、隐私号码、base helpers、路由及静态目录入口。
- `npm run build`：TypeScript 与 Vite 构建，postbuild 生成所有已知页面入口及 404。
- `python tests/visual_review.py`：真实 Chromium + 普通静态文件服务，不依赖 Vite 的自动 SPA 200 回退。
- 再以 `/embedded-association-site/` 为 base 构建，通过 `REVIEW_BASE_PATH` 指定相同前缀运行完整浏览器验收。

构建与测试顺序执行，不在浏览器检查尚未完成时覆盖 dist。测试服务使用临时空闲端口，并在结束时关闭；指定 `REVIEW_BASE_URL` 后测试线上 URL，不额外启动服务。

## 浏览器覆盖范围

路由来自主页面清单和 site.json：8 个主页面、3 个项目详情、3 个活动详情，以及未知地址的 404 页面。

- 1440×1000 与 390×844：30 张完整页面截图；另有深色首页及 320 / 390px 首屏、电路区域和菜单截图。
- 320 / 360 / 768 / 1024 / 1920 像素：全部 14 个公开路由的横向溢出检查。
- 已知路由直接打开、刷新必须 HTTP 200；未知路由必须 HTTP 404，并显示应用内未找到页面。
- 检查图片成功解码，且内容中声明的真实图片仍以 img 呈现；不能通过静默替换 SVG 让测试“通过”。另检查首页背景、资源前缀、错误响应及 console/pageerror。
- 主页面正文不得出现过期的概念示例/待核实标签；缺少资料的明确提示与成员中性头像予以保留。
- 搜索、筛选、空状态恢复、学习路线与 JSON 同步、禁用纳新入口、FAQ、主题持久化、浏览器历史/查询串、手机菜单和系统功能组内容/几何边界。
- 320×568 / 390×844 触控上下文检查主要控件 44px、搜索文字 16px、tap 操作、菜单首尾入口、Escape/关闭按钮、焦点返回及滚动锁定。
- 故意注入两张不存在的项目/活动图片，验证缺图提示且无 SVG 回退；这两次预期的 404 与未知路由 404 不属于产品资源错误。

## 视觉复核重点

保留深蓝/白色主题，优化首页顺序和手机布局。检查全部页面的桌面/手机截图，并重点放大检查电路图主体与文字对比、学习路线、项目图注、团队字段换行、缺图状态、真实活动照片和手机导航。电路图成功解码不能证明视觉上清楚，必须检查首屏与独立图片区域；项目组成以功能组呈现，不暗示终端按单线串联。

## 证据与边界

本轮将竞赛荣誉入口前移至首页首屏和介绍正文，并在两页简介后展示代表成果。根路径与 Pages 子路径各通过 707 项浏览器检查、生成 36 张报告截图；20 项内容测试和两种构建通过。增加了摘要数据一致性与手机直接进入完整记录的检查，详见 [荣誉入口前移](2026-10-13-awards-visibility.md)。

上一轮（PR #5）根路径与 Pages 子路径各完成 519 项浏览器检查，详见保留的 round2-final-root / round2-final-pages 报告。手机视觉版本（PR #6）的验收目录为 mobile-polish-final-root / mobile-polish-final-pages，报告独立保存，避免混用证据。该版本 19 项 Node 测试与两种 base 的 TypeScript/Vite 构建均通过；两套浏览器验收各完成 646 项检查、36 张报告内截图及单独的深色首页截图，errors 均为空。

荣誉版本（PR #7）：20 项 Node 测试、两种 base 构建均通过；awards-final-root / awards-final-pages 各 657 项浏览器检查、36 张报告内截图及单独深色首页截图，errors 均为空。新增荣誉搜索、校级筛选、公开字段范围和教师信息省略检查。材料核对见 [荣誉发布记录](2026-10-13-awards.md)。

当前 FPGA 内容版本：20 项 Node 测试、两种 base 构建均通过；fpga-final-root / fpga-final-pages 各 665 项浏览器检查、36 张报告内截图，errors 均为空。两条学习路线及 FPGA 分类跳转、刷新、搜索已验收；范围和官方来源见 [FPGA 发布记录](2026-10-13-fpga.md)。

本地结果保存在未提交的 `artifacts/review/`；CI 的 `website-visual-review` 工件分别保存 root/pages 报告和截图。`results.json` 中 mode 为 `production build` 才表示实际构建测试；`deployed site` 表示访问指定线上站点。Actions 与部署是否成功必须查看对应提交的运行结果，不能由本地通过推定。

INLINE_REVIEW_TEMPLATE 仅为历史受限环境保留的组件检查方式，不证明 HTTP 路由、原生存储或生产部署。当前验收没有使用该模式。

浏览器的手机视口验收不等于真实 iOS/Android 真机或大陆校园网访问实测。高清项目原图、报名入口和教程 PDF 尚未补齐，本轮没有伪造这些材料。
