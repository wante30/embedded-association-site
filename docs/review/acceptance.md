## 退回与修复记录

1. **培训配图不匹配：** LED 入门活动原来复用视觉设备示意，不能表达主题。改为独立 MCU 开发板 + LED 概念 SVG，并重验首页、活动列表与详情。
2. **中文孤字换行：** 手机首页与招新区部分标题最后一个字独占一行。标题使用平衡换行，重验桌面与手机。
3. **流程箭头歧义：** 项目架构在窄屏折为多行，但箭头仍向右。600px 以下改为单列、向下箭头，增加浏览器断言。
4. **资料不可直接替换：** 项目和成员新增 image 字段；活动图片实际读取该字段，失效时回退概念图。
5. **仅查询串变化未更新：** 路由订阅 pathname + search，资源组件随查询变化重新选择初始分类，增加回归检查。真实历史前进/后退在 CI 中验证。

## 自动生产检查

`.github/workflows/quality.yml` 运行锁定依赖安装、Node 内容测试、TypeScript + Vite build、原生 Chromium 页面截图与交互检查，并输出 `website-visual-review`、`website-dist`、`website-source` 三个构建工件。`results.json` 中的 mode 必须为 `production build` 才是生产测试证据。最终结果以实际运行日志与工件为准。
