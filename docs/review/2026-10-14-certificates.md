# 荣誉材料公开副本与手机大图

## 范围

用户明确要求在荣誉页加入证书图片、遮盖身份证号与指导教师信息，随后确认采用本地脚本实色遮盖，不使用 AI 重绘。本轮为原有 16 条记录添加对应图片：14 张证书、2 张成绩截图。赛事、奖项、级别与成员文案保持原样；未恢复此前排除的记录。

## 脱敏与来源

- 合并 PDF 仅使用第 1、2、4、5 页，对应已公开的 4 条记录；其余图片对应此前逐张核对的材料。
- 通过不透明实色覆盖身份证号和完整教师信息行，验证二维码也覆盖；校赛截图隐藏其他队伍及内部队伍编号，保留赛事标题、表头和相关成员获奖行。
- 高清图采用无损 WebP，并逐份比较：遮盖范围以外的 RGB 像素与来源图一致。PDF 来源以原页面渲染图为比较基准。
- 缩略图仅从已脱敏的高清结果生成。公开文件不含 EXIF/XMP、动画、PDF 文字层或原件附件。
- 原件与处理脚本留在仓库外的本地暂存目录；未脱敏证书、完整 PDF 和 ZIP 未加入 Git。
- 公开素材对应关系、尺寸、文件哈希和遮盖区域记录在 `certificates-manifest.json`；人工复核负责确认区域选取，自动检查负责检测像素、文件与交互回归。

## 页面行为

荣誉卡片展示小缩略图。点击后使用原生模态对话框展示公开高清副本，提供适应屏幕、放大滚动、单独打开、关闭和 Escape 操作。关闭时恢复缩略图焦点与背景滚动，Tab 在模态框内循环；图片失败显示明确提示。资源路径继续使用 `assetPath`，不修改既有路由或 Pages 配置。没有新增生产依赖。

## 验收方式

- Node 测试验证 16 份材料与原有记录对应、32 个公开图片文件无遗漏或额外文件、哈希、WebP 容器、无 EXIF/XMP/动画；原有内容与子路径契约保留。
- `certificate_review.py` 通过真实页面逐一打开 16 份高清图，核对尺寸、实际遮盖像素和资源路径；在 320 / 390px 检查缩略图触控、放大与滚动、键盘焦点及关闭恢复。
- `visual_review.py` 继续覆盖所有公开路由、真实照片、手机视口、控制台与深链接；分别对根路径和 Pages 子路径的生产构建运行。

报告与截图保存在 `artifacts/review/certificates-root`、`certificates-pages`；手机验收采用 Chromium 触控模拟。部署和线上结论以最终提交对应的 Actions 与实际网址复查为准。

本地结果：22 项 Node 测试通过；TypeScript 与 Vite 根路径、Pages 子路径构建通过。两种构建各完成 1,016 项浏览器检查、36 张报告内标准截图和补充证书弹窗截图，错误列表为空。16 份高清图的遮盖区域已通过浏览器像素检查，公开副本在遮盖区域以外与来源图一致。
