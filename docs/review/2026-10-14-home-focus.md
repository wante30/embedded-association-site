# 首页手机端与重点内容打磨

## 范围与依据

从 master `6dd435b` 建立分支。用户要求保留深蓝电路风格，增强手机首屏电路图，突出慧枢与竞赛荣誉，减少卡片感。页面、事实数据、既有照片与证书脱敏副本沿用原项目，不生成新的实物或成果。

原首页手机端将文案与电路图分成上下两段，重点项目位于三条荣誉摘要之后。新布局使用整段电路背景，按钮下方预留可见图像；首屏直接进入慧枢详情或荣誉页；主内容按慧枢、荣誉、学习方向与活动排列。

## 设计

- 沿用电路深蓝 `#071622`、背景深蓝 `#06141f`、展陈蓝 `#0c2230`、纸白 `#ffffff`、电光蓝 `#246bfd` 与浅电蓝 `#88d9ff`。
- 中文标题与正文沿用系统无衬线字体，项目短名放大，技术标记使用系统等宽字体；不加载网络字体。
- 慧枢以项目短名、完整副标题、实物图和技术说明构成开放图文，技术标签改为一行文字；历史项目保留文字入口。
- 荣誉采用深蓝背景、真实证书缩略展陈与排版简洁的成果记录，使用同一份 awards 数据；协会介绍页保留原有荣誉摘要布局。
- 首页独有规则移入 home.css，清除 pages.css 中原有重复首页规则。沿用既有滚动入场机制与减少动态效果支持，不引入生产依赖。

## 图片与验证

首屏使用已有 602px WebP 与 2000px JPEG，通过 picture / srcset 适配屏幕宽度与像素密度，并提高请求优先级。其余真实图片和证书路径继续经过 assetPath；荣誉只请求缩略图，高清证书由独立荣誉页按需加载。

保留原有内容、子路径与全站浏览器检查。新增首页专项验收覆盖 320 / 360 / 390 / 430 / 768 / 1440px、深浅主题和 2x 像素密度，检查首屏按钮、至少 90px 无文字遮挡的电路区域、实际截图图像细节、图片来源、主次内容顺序和荣誉预览。Pillow 只用于测试截图的像素统计。

测试与截图记录在 artifacts/review/home-root、home-pages；部署结论以最终提交对应的 Actions 和线上复查为准。
