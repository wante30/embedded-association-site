# 首页重心与荣誉位置修正

## 本轮范围

按用户最新反馈收回上一轮对慧枢与荣誉的过度强调。首页代表协会，首屏入口调整为“了解协会”和“学习资源”；保留手机端电路背景、真实活动照片与滚动渐显。

页面顺序为协会首屏、基本信息、实践方向、实际活动、项目实践、加入我们、竞赛荣誉入口。竞赛荣誉位于首页内容最底部、全站页脚之前；不展示整块证书拼贴、代表奖项卡片或获奖数量。完整证书墙与文字档案仍在荣誉页。

三个真实项目按内容源顺序、同等字号展示标题、年份与摘要。取消慧枢独立的大幅标题、系统模块、技术清单和首页项目按钮；项目资料与详情页保留。

## 验证边界

浏览器回归覆盖首页顺序、荣誉最终位置与紧凑高度、项目标题同等字号、两个首屏入口实际跳转、手机端荣誉入口触控，以及原有首屏电路图片解码、不同像素比、深浅主题、横向溢出检查。原有荣誉证书脱敏与大图、全站图片、路由刷新、子路径、菜单及动效验收继续执行。

不修改内容事实、原始资料、证书公开副本、项目详情、技术栈、路由与部署配置。本文件取代上一轮首页重点项目及证书拼贴布局的当前描述；旧验收记录仅作历史证据。实际测试与部署结果以本轮 PR 和报告为准。
