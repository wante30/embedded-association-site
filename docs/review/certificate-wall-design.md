# 证书墙与全站视觉调整

目标：面向集成电路专业学生，以真实证书、硬件照片和项目资料形成协会官网的辨识度。保留 React / Vite、自定义路由和 Pages 子路径。

## 视觉方向

- 色彩：电路深蓝 `#071622`、展墙蓝 `#102634`、纸白 `#ffffff`、背景灰蓝 `#f4f7fa`、电光蓝 `#246bfd`、浅电蓝 `#88d9ff`。
- 字体：正文沿用本地系统中文无衬线；标题增加留白与字号层级；年份和技术标记使用系统等宽字体。无需下载字体。
- 布局：证书页采用上方展墙、下方按年排列的文字档案；项目采用大图与说明交错排列；学习资源采用目录条目。去掉重复外框、圆角与阴影，只在真实图片和交互控件上保留必要边界。
- 记忆点：深蓝展墙中完整呈现不同尺寸的真实证书，移动端可点击、放大、平移查看。

## 取舍与验收

不增加装饰编号、粒子、持续运动或第三方动画库。证书墙作为主要视觉变化，其他区域以图文比例、间距和分隔线改善层级，避免把整站改成另一套模板。

滚动入场使用一次性的轻微位移与淡入。首屏内容立即可读；减少动态效果、观察器不可用时直接显示；键盘聚焦直接显示。筛选新增内容也应正常可见。

证书从原件重新生成：指导教师正常展示；身份证号、验证二维码及无关名单继续实色遮盖。只发布扁平化副本与缩略图，原件保留在仓库外。

验证包含内容测试、TypeScript / Vite 构建、根路径和 Pages 子路径视觉检查、证书大图交互、移动端溢出、动态效果与减少动态效果、CI 和部署后验证。
