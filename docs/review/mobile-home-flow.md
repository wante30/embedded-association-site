# 手机首页连续版面调整

## 发现与处理

移除卡片边框后，手机首页仍保留两列图标宫格、逐块堆叠的栏目标题与按钮，以及反复切换的浅色底板，因此视觉上仍像一组独立卡片。

本轮将学习方向改成单列目录，保留七个方向、技术说明和原来的分类链接。收起重复图标，使用轻量箭头提示整行可进入。FPGA 保留第一位与蓝色文字。

手机端学习、活动、项目共用连续底色；栏目标题与浏览入口同行，减少英文眉题与独立按钮行。活动首张实拍以通栏照片呈现，后两条保留缩略图、标题与日期，形成连续图文记录。项目按已有年份组织为细线时间记录，三项保持同等字号。加入入口使用简洁文字链接，减少独立色块。

## 保留的边界

首屏电路背景、协会身份、首屏入口、资料事实与所有活动照片不变。完整深蓝荣誉区继续位于首页最底部，证书拼贴、三条摘要和完整荣誉页入口都保留。桌面布局延续现有结构，仅两个首页栏目标题简化为“学习与实践”“协会活动”。不调整其他页面版式，不修改路由、子路径、证书脱敏或部署配置，不增加依赖。

## 验收

复用原有全站浏览器回归，同时检查方向与活动内容完整、手机目录单列且触控区足够、栏目入口与标题同行不重叠、活动分类与日期不遮挡标题。保存学习目录与活动版面截图，人工复核 390px、320px、深浅主题及桌面。构建与部署结果以本轮 PR 和验收报告为准。
